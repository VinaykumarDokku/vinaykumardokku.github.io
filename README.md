## 💻 Run Locally

You don't need Angular, Node.js, Docker, or an `npm install` step to view this static portfolio.

**1. Clone the repository**

```bash
git clone https://github.com/VinaykumarDokku/vinaykumardokku.github.io.git
cd vinaykumardokku.github.io
```

**2. Open the website**

Open `index.html` in your browser. For a local web server, you can alternatively run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000/`.

## 🚀 Deploy to GitHub Pages

1. Push the website files to the **`main`** branch of [this repository](https://github.com/VinaykumarDokku/vinaykumardokku.github.io).
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **`main`** and **`/(root)`**, then save.
5. Visit **https://vinaykumardokku.github.io/** after deployment completes.
